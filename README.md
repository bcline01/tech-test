# tech-test![MIT](https://img.shields.io/badge/license-MIT-green)

## Description
This project adds comprehensive testing to an existing Tech Quiz application built with the MERN stack. The app allows users to take a quiz with ten random questions and view their final score. The testing suite uses Cypress to implement both component and end-to-end tests for key functionalities.

  ## Installation
  Clone the respository from my **[GitHub](https://github.com/bcline01/tech-test)**

   <br>NPM: Use the command "npm i" to install Node Package Manager<br>
  <br>Install Cypress: npm install cypress --save-dev<br>
  <br>Navigate Cypress for both component and end to end testing<br>
   
  ## Usage
  Initialize program by running the application in the integrated terminal "npm run start:dev"
  
  Then in a seperate integrated terminal "npm run cypress"
